# User Story - US_011

## Story ID
* ID Format: US_011

## Story Title
* 15-Minute Session Timeout with Countdown Modal

## Description
* As an authenticated user, I want the system to warn me 2 minutes before my session expires and automatically log me out after 15 minutes of inactivity, so that unauthorised access to my account is prevented when I leave my device unattended.

## Acceptance Criteria

### AC-001: Session terminates after 15 minutes of inactivity
- **Given**: An authenticated user has made no interaction for exactly 15 minutes
- **When**: The system detects the inactivity threshold
- **Then**: The server-side session token is invalidated; a session-timeout audit event is written; the user's next request returns HTTP 401 and the React SPA redirects to the login page with a "Session expired" message (UC-003)

### AC-002: Inactivity timer resets on user interaction
- **Given**: An authenticated user has been inactive for 12 minutes
- **When**: The user performs any interaction (click, keypress, or scroll)
- **Then**: The inactivity timer resets to 0; no modal appears; the session remains active (UC-003 Extension 1a)

### AC-003: Countdown modal appears at 2 minutes before expiry
- **Given**: An authenticated user has been inactive for exactly 13 minutes
- **When**: The 13-minute threshold is crossed
- **Then**: A modal dialog appears with a countdown from 120 seconds; the modal is announced to screen readers via `aria-live="assertive"` with the text "Session expiring in 2 minutes"; the "Stay logged in" CTA is visible and focusable (UXR-503, UXR-205)

### AC-004: "Stay logged in" extends the session
- **Given**: The session timeout countdown modal is displayed
- **When**: The user clicks or activates the "Stay logged in" CTA
- **Then**: The inactivity timer resets to 0; the modal closes; the session remains active; no re-authentication is required

### AC-005: Session expires if user ignores the modal
- **Given**: The session timeout countdown modal is displayed and the user takes no action
- **When**: The countdown reaches 0
- **Then**: The session token is invalidated immediately; the modal transitions to a "Session expired" message; the user is redirected to the login page within 1 second

## Edge Cases
* User has multiple browser tabs open → session expiry in one tab invalidates the shared server-side token; all other tabs detect the 401 on their next API call and redirect to login independently
* Countdown modal is rendered when JavaScript is executing a long-running task → modal rendering is not blocked by synchronous JS; `requestAnimationFrame` or a Web Worker timer is used to ensure the countdown remains accurate
* Screen reader is active when modal appears → `aria-live="assertive"` announcement is made without requiring the user to move keyboard focus; the "Stay logged in" button is reachable via Tab from the announced region
