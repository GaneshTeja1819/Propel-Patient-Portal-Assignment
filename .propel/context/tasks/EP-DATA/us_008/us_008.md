# User Story - US_008

## Story ID
* ID Format: US_008

## Story Title
* Implement RBAC Policies and Gemini SDK Configuration

## Description
* As a developer, I want ASP.NET Core RBAC policies (PatientPolicy, StaffPolicy, AdminPolicy) enforced on all API endpoints and the Gemini API SDK configured with structured output mode and per-invocation logging, so that every request is role-gated and AI features have a consistent, auditable invocation foundation.

## Acceptance Criteria

### AC-001: PatientPolicy blocks Staff and Admin routes
- **Given**: Three RBAC policies are registered: PatientPolicy, StaffPolicy, AdminPolicy
- **When**: An authenticated Patient attempts to call a `[Authorize(Policy = "StaffPolicy")]` endpoint
- **Then**: The API returns HTTP 403; the Patient's JWT role claim is logged; no business logic executes (TR-008, NFR-005)

### AC-002: Each policy is enforced at controller action level
- **Given**: API controllers have `[Authorize(Policy = "...")]` attributes on all actions
- **When**: An unauthenticated request is sent to any protected endpoint
- **Then**: The API returns HTTP 401; no data is returned; the absence of a valid JWT is logged

### AC-003: Gemini SDK sends structured output with JSON schema
- **Given**: The Gemini SDK client is configured in the Infrastructure layer with the `gemini-1.5-pro` model and a JSON schema for a target response type
- **When**: A test invocation is made with a sample prompt
- **Then**: The SDK returns a response that deserialises without error into the target C# type; the response does not require regex parsing

### AC-004: Gemini invocation logging captures required metadata
- **Given**: The Gemini invocation logging middleware is active
- **When**: Any Gemini API call completes (success or failure)
- **Then**: An `AI_INVOCATION` audit log entry is written containing: modelVersion, promptHash (SHA-256), inputTokenCount, outputTokenCount, responseLatencyMs, httpStatusCode, and timestamp (AIR-006)

### AC-005: PdfPig library is integrated in the Infrastructure layer
- **Given**: The PdfPig NuGet package is added to the Infrastructure project
- **When**: A sample PDF file is passed to the `IPdfTextExtractor` interface implementation
- **Then**: The implementation returns the extracted text as a non-null string; the result can be passed to Gemini without further processing (TR-017)

## Edge Cases
* Role claim is missing from the JWT → RBAC middleware returns HTTP 401 before policy evaluation; no role-specific logic executes
* Gemini API key is not configured → the SDK throws a configuration exception at startup; the application logs the error and exits with a non-zero code; no request reaches the Gemini endpoint
* PdfPig encounters a corrupted PDF → the extractor catches the exception, logs the document ID and error, and returns an empty string; the caller treats an empty string as an extraction failure
