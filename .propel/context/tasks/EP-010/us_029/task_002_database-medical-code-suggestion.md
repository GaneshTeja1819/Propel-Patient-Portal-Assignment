## Task Overview
Extend the `MedicalCodeSuggestion` entity with four new fields required by US_029: `Rank` (AC-002 ranked candidates), `Status` (Pending/Accepted/Modified/Rejected — drives the idempotency guard in `CodeSuggestionJob`), `ModelVersion` and `PromptHash` (AIR-006 traceability for AC-004). Configure column mappings and a composite index on `(ClinicalDataId, Status)` in `AppDbContext`, then generate and apply an EF Core migration. This task is a prerequisite for `task_001_ai-code-suggestion.md`.

## Dependent Tasks
- None — this task unblocks `task_001_ai-code-suggestion.md` (Backend)

## Impacted Components
- `backend/src/UPACIP.Domain/Entities/MedicalCodeSuggestion.cs` — entity: add Rank, Status, ModelVersion, PromptHash properties
- `backend/src/UPACIP.Infrastructure/Persistence/AppDbContext.cs` — EF Core config: column mappings, default value for Status, composite index
- `backend/src/UPACIP.Infrastructure/Migrations/` — new migration file for the schema extension

## Implementation Plan
1. Open `MedicalCodeSuggestion.cs` and add four properties:
   ```csharp
   public int Rank { get; set; }                                // AC-002: ranked position (1 = highest)
   public string Status { get; set; } = "Pending";             // Pending | Accepted | Modified | Rejected
   public string ModelVersion { get; set; } = string.Empty;   // AIR-006: Gemini model identifier logged per call
   public string PromptHash { get; set; } = string.Empty;     // AIR-006: SHA-256 of prompt template
   ```
2. In `AppDbContext.cs`, within the `MedicalCodeSuggestion` EF configuration block, add:
   - `.Property(e => e.Rank).HasColumnName("rank").IsRequired()`
   - `.Property(e => e.Status).HasColumnName("status").HasMaxLength(32).HasDefaultValue("Pending").IsRequired()`
   - `.Property(e => e.ModelVersion).HasColumnName("model_version").HasMaxLength(128).IsRequired()`
   - `.Property(e => e.PromptHash).HasColumnName("prompt_hash").HasMaxLength(64).IsRequired()`
   - `.HasIndex(e => new { e.ClinicalDataId, e.Status }).HasDatabaseName("IX_MedicalCodeSuggestion_ClinicalDataId_Status")`
3. Generate EF Core migration:
   ```
   dotnet ef migrations add AddRankStatusAuditFieldsToMedicalCodeSuggestion --project UPACIP.Infrastructure --startup-project UPACIP.API
   ```
4. Review generated migration: confirm `rank`, `status` (defaultValue: "Pending"), `model_version`, `prompt_hash` columns added; `IX_MedicalCodeSuggestion_ClinicalDataId_Status` index created; no destructive operations.
