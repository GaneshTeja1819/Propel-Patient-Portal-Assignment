# User Story - US_019

## Story ID
* ID Format: US_019

## Story Title
* Manual Intake Form and AI/Manual Mode Switch

## Description
* As an authenticated Patient, I want to complete my intake using a structured manual form or switch between the manual and AI modes at any point without losing my answers, so that I can choose the input method I prefer and never have to re-enter information I have already provided.

## Acceptance Criteria

### AC-001: Manual intake form presents all structured intake fields
- **Given**: An authenticated Patient selects the manual intake pathway
- **When**: The manual intake form renders
- **Then**: All defined intake fields (identical to the AI intake field set) are displayed as labelled form inputs; required fields are visually marked; the form is accessible with htmlFor/id label associations (FR-016, UC-010, UXR-203)

### AC-002: Required field validation blocks submission
- **Given**: The Patient attempts to submit the manual intake form with one or more required fields empty
- **When**: The submit action is triggered
- **Then**: The submission is blocked; missing required fields are highlighted with an inline error message linked via `aria-describedby`; the first invalid field receives focus (UC-010 Extension 4a)

### AC-003: Confirmed manual intake is persisted with audit entry
- **Given**: The Patient fills in all required fields and submits
- **When**: The form submission is processed
- **Then**: An IntakeRecord is created linked to the appointmentId with method = "Manual"; PHI fields are encrypted before persistence; an audit log entry is written (UC-010)

### AC-004: Switching from AI to manual preserves all captured fields
- **Given**: The Patient is in the AI intake conversation with some fields already captured
- **When**: The Patient selects the "Switch to manual form" option
- **Then**: All fields captured so far are pre-populated in the manual form; no previously entered data is lost; the Patient can continue from the switch point (FR-017, UC-011, UXR-103)

### AC-005: Switching from manual to AI preserves all entered fields
- **Given**: The Patient has partially filled the manual intake form
- **When**: The Patient selects the "Switch to AI chat" option
- **Then**: All fields already entered are populated in the AI conversation context; the AI skips already-answered fields and continues from the first unanswered field; no data is lost (FR-017, UC-011, UXR-103)

## Edge Cases
* A field captured in the AI mode has no exact equivalent in the manual form → the field is flagged for manual entry in the manual form view; the Patient is prompted to review it; the field is not silently discarded
* Patient switches modes multiple times → each switch preserves all fields from the previous mode; the final mode at submission time determines the IntakeRecord.method value
* Manual form submitted with all optional fields blank → the record is persisted with null values for optional fields; no validation error is shown for optional fields
