# User Story - US_004

## Story ID
* ID Format: US_004

## Story Title
* Set Up GitHub Actions CI/CD Pipelines

## Description
* As a DevOps engineer, I want GitHub Actions CI/CD pipelines for both the React frontend and .NET backend that build, test, and deploy on every push to main, so that the team can ship with confidence and all secrets are managed exclusively through GitHub Secrets.

## Acceptance Criteria

### AC-001: Frontend CI pipeline builds and deploys
- **Given**: A GitHub Actions workflow exists for the React SPA
- **When**: A commit is pushed to the main branch
- **Then**: The workflow runs `npm install`, `npm run build`, executes frontend tests, and deploys the build artefact to InfinityFree; the workflow completes with exit code 0

### AC-002: Backend CI pipeline builds, tests, and deploys
- **Given**: A GitHub Actions workflow exists for the .NET 8 API
- **When**: A commit is pushed to the main branch
- **Then**: The workflow runs `dotnet build`, `dotnet test`, publishes the artefact, deploys to MonsterASP/IIS, and calls `/api/v1/health` to confirm a 200 response; the workflow completes with exit code 0

### AC-003: All credentials sourced from GitHub Secrets
- **Given**: The CI workflows reference connection strings, API keys, and deployment credentials
- **When**: A static secret scan runs against the workflow YAML files
- **Then**: Zero raw credential values are found; all sensitive values reference `${{ secrets.SECRET_NAME }}` syntax

### AC-004: Failed test gate blocks deployment
- **Given**: A unit test is intentionally broken in the backend
- **When**: The CI pipeline runs
- **Then**: The `dotnet test` step exits with a non-zero code; the deploy step is skipped; the pipeline reports failure and no artefact is deployed

### AC-005: Pipeline completes within free-tier Actions minutes
- **Given**: Both pipelines run on `ubuntu-latest` (free tier runner)
- **When**: Both pipelines execute back-to-back on a standard commit
- **Then**: Each pipeline completes within 10 minutes; combined monthly usage stays within GitHub Actions free-tier limits (NFR-010)

## Edge Cases
* MonsterASP FTP/deployment endpoint unavailable → deployment step fails with a timeout error; pipeline exits non-zero; Slack/email notification is sent if configured
* GitHub Secrets missing from environment → pipeline fails at the step that references the missing secret with a descriptive error message; no partial deployment occurs
* Free-tier Actions minutes exhausted for the month → pipeline queues or fails with a quota-exceeded message; team is notified to review pipeline efficiency
