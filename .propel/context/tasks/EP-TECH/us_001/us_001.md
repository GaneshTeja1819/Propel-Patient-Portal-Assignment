# User Story - US_001

## Story ID
* ID Format: US_001

## Story Title
* Scaffold React 18 SPA with Design Token System

## Description
* As a developer, I want a fully scaffolded React 18 SPA deployed to InfinityFree with a CSS design token system and WCAG 2.2 AA accessibility baseline, so that all feature teams can build UI components against a consistent, accessible foundation from day one.

## Acceptance Criteria

### AC-001: React SPA scaffold builds and deploys successfully
- **Given**: The React 18 project scaffold exists with ESLint, Prettier, and a component baseline
- **When**: The GitHub Actions CI pipeline runs on the main branch
- **Then**: The build completes without errors and the SPA is accessible at the InfinityFree production URL

### AC-002: CSS design token system is active
- **Given**: The design token stylesheet (variables.css or equivalent) is loaded globally
- **When**: Any component renders in the browser
- **Then**: All colour, spacing, typography, radius, and elevation values resolve from token variables; no raw hex or pixel values exist outside the primitive token table (automated token audit passes with zero violations — UXR-401)

### AC-003: WCAG 2.2 AA contrast baseline enforced
- **Given**: The design token set defines all foreground/background colour pairings
- **When**: An automated axe-core scan runs against the baseline component page
- **Then**: Zero colour-contrast violations are reported; normal text contrast ≥ 4.5:1 and large text / UI component contrast ≥ 3:1 (UXR-201)

### AC-004: Keyboard navigation baseline is functional
- **Given**: The component baseline page is rendered
- **When**: A user navigates using only the Tab key
- **Then**: Focus moves in logical DOM order; all interactive elements are reachable; the focus ring is ≥ 3 px offset with ≥ 3:1 contrast against the adjacent surface (UXR-202)

### AC-005: Responsive breakpoints are established
- **Given**: The CSS baseline includes breakpoint definitions at 375 px, 768 px, and 1280 px
- **When**: The SPA is rendered at each breakpoint in a browser viewport
- **Then**: No horizontal scroll appears; content is readable without zoom; touch targets measure ≥ 44 × 44 px at 375 px (UXR-301)

## Edge Cases
* Token file missing or fails to load → browser falls back to inherited values; CI build step fails if token file is absent from the build output
* InfinityFree free-tier file size limit exceeded → CI gate rejects build artefact above the documented size threshold
* axe-core scan produces false positive on a third-party library component → documented suppression list updated; all project-owned components must pass with zero violations
