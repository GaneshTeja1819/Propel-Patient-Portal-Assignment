## 🔴 Critical Findings

### CR-001 — IDOR: Appointment Ownership Not Verified

| Field | Detail |
|-------|--------|
| **File** | `backend/src/UPACIP.API/Controllers/IntakeController.cs` |
| **Lines** | 221–227 |
| **OWASP** | A01:2021 — Broken Access Control |
| **CWE** | CWE-639 |

**Code:**
```csharp
private bool ValidateAppointmentOwnership(Guid appointmentId)
{
    var sub = User.FindFirstValue("sub");
    return !string.IsNullOrWhiteSpace(sub) && appointmentId != Guid.Empty;
}
```

**Risk:** Any authenticated patient can read, append answers to, and confirm *any other patient's* intake session simply by knowing the GUID. PHI (medications, allergies, chief complaint) is fully exposed. This is an OWASP A01 IDOR of the highest severity in a HIPAA-regulated system.

**Fix:**
```csharp
private async Task<bool> ValidateAppointmentOwnershipAsync(
    Guid appointmentId,
    CancellationToken ct)
{
    var sub = User.FindFirstValue("sub");
    if (string.IsNullOrWhiteSpace(sub) || appointmentId == Guid.Empty) return false;
    var patientId = await _repo.GetAppointmentPatientIdAsync(appointmentId, ct);
    return patientId == Guid.Parse(sub);
}
```

Update all callers to `await ValidateAppointmentOwnershipAsync(appointmentId, ct)` and return `403 Forbid()` (not `404`) on failure.

### CR-003 — Missing MIME Type and Magic-Bytes Validation

| Field | Detail |
|-------|--------|
| **File** | `backend/src/UPACIP.API/Controllers/DocumentsController.cs` |
| **Line** | ~79 |
| **OWASP** | A03:2021 — Injection |

**Code:**
```csharp
MimeType: file.ContentType,   // ContentType is attacker-controlled
```

`file.ContentType` is the value the browser sets in the multipart request — an attacker can send any string. No validation verifies the uploaded bytes are a legitimate PDF before they are stored in Supabase and dispatched to PdfPig.

**Fix:**
```csharp
private static readonly byte[] PdfMagicBytes = "%PDF"u8.ToArray();

private static bool IsPdf(IFormFile file)
{
    using var stream = file.OpenReadStream();
    Span<byte> header = stackalloc byte[4];
    return stream.Read(header) == 4 && header.SequenceEqual(PdfMagicBytes);
}
```

Add before command construction:
```csharp
if (!IsPdf(file))
    return BadRequest(new { message = "Only PDF files are accepted." });
```

Also restrict `documentType` to an allowlist (see CR-012).

### CR-007 — AbortController Never Cancelled on Unmount

| Field | Detail |
|-------|--------|
| **File** | `frontend/src/hooks/useAIIntake.ts` |
| **Line** | ~119 |

`const ac = new AbortController()` is created inside `startSession()`. The `ac` reference is not stored in a `useRef`; `ac.abort()` is never called in a cleanup function. Under React 18 Strict Mode (double-invoke), two concurrent `POST /intake/start` calls are fired. If the component unmounts before the second settles, `setMessages` / `setPhase` are called on an unmounted component, causing a memory leak and potential state corruption.

**Fix:**
```ts
const abortRef = useRef<AbortController | null>(null);

const startSession = useCallback(async () => {
    abortRef.current?.abort();
    abortRef.current = new AbortController();
    const { signal } = abortRef.current;
    // ...existing fetch calls using signal...
}, [...deps]);

useEffect(() => {
    return () => { abortRef.current?.abort(); };
}, []);
```

### CR-009 — No Per-Session Rate Limit on Gemini API Calls

| Field | Detail |
|-------|--------|
| **Files** | `backend/src/UPACIP.Infrastructure/AI/GeminiIntakeAdapter.cs`, `IntakeController.cs` |
| **OWASP** | A05:2021 — Security Misconfiguration (cost/availability) |

Every call to `POST /api/v1/intake/answer` triggers a Gemini API call with no per-session, per-patient, or global call-count guard. A malicious (or buggy) client looping requests can exhaust the Gemini quota and generate unbounded API charges.

**Fix:** Introduce a session-scoped call counter in Redis. Reject with `HTTP 429` once the limit (e.g., `2 × totalQuestions`) is exceeded:
```csharp
var callCount = await _redis.StringIncrementAsync($"gemini-calls:{appointmentId}");
if (callCount > _options.MaxCallsPerSession)
    return Results.StatusCode(429);
```

### CR-010 — Prompt Injection Fence Breakable via `</patient_answer>`

| Field | Detail |
|-------|--------|

| **Line** | ~57 |

```csharp
var fencedAnswer = $"<patient_answer>{rawAnswer}</patient_answer>";
```

If a patient submits a response containing `</patient_answer>` followed by adversarial instructions, the XML-style fence is broken and the injected text may be processed as model instructions.

**Fix:**
```csharp
var escaped = rawAnswer
    .Replace("&",  "&amp;")
    .Replace("<",  "&lt;")
    .Replace(">",  "&gt;");
var fencedAnswer = $"<patient_answer>{escaped}</patient_answer>";
```

### CR-011 — Static In-Memory PHI Store Has No TTL

| Field | Detail |
|-------|--------|
| **File** | `backend/src/UPACIP.Infrastructure/AI/IntakeSessionService.cs` |
| **Line** | ~38 |

```csharp
private static readonly ConcurrentDictionary<string, string> _memoryStore = new();
```

`_memoryStore` is static, so it persists for the lifetime of the application process. When Redis is unavailable (dev/test), session state containing PHI (medications, allergies, SSN-adjacent data) is written here and never evicted. If the fallback is triggered in a staging environment under load, PHI will accumulate until the process restarts.

**Fix:** Wrap the fallback dictionary with a simple TTL mechanism:
```csharp
private static readonly MemoryCache _fallbackCache =
    new MemoryCache(new MemoryCacheOptions { SizeLimit = 1000 });

// On set:
_fallbackCache.Set(key, value,
    new MemoryCacheEntryOptions()
        .SetSlidingExpiration(SessionTtl)
        .SetSize(1));
```

### CR-014 — `JSON.parse` Cast Without Runtime Type Guard

| Field | Detail |
|-------|--------|
| **File** | `frontend/src/hooks/useAIIntake.ts` |
| **Line** | ~65 |

```ts
JSON.parse(raw) as Partial<IntakeSessionState>
```

`as` is a TypeScript compile-time cast — it does not validate the parsed structure at runtime. Corrupted or outdated `sessionStorage` values (e.g., from a previous schema version) will pass through without error, potentially causing `undefined` property access downstream.

**Fix:** Add a minimal runtime guard:
```ts
const parsed = JSON.parse(raw);
if (!parsed || typeof parsed !== 'object') return null;
return parsed as Partial<IntakeSessionState>;
```
